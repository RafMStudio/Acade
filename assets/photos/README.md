# Photos

Drop photos here and run `npm run build`. Each slot uses the first file it finds
(`.webp`, then `.jpg`). Until a file exists, the slot shows artwork generated
from the Itqan logo.

| File | Where it shows | Shape |
| --- | --- | --- |
| `campus.jpg` | Sign-in screen, large tile | Landscape or portrait, at least 1400 wide |
| `hero-hod.jpg` | Head of Department overview | Landscape, at least 1400 wide |
| `hero-coordinator.jpg` | Coordinator overview | Landscape |
| `hero-instructor.jpg` | Instructor overview | Landscape |
| `hero-supervisor.jpg` | APU, VDAA and System Administrator overview | Landscape |

The current set was generated by the project owner for Itqan.

## Rules for every photo

- Realistic, natural light, Saudi university setting.
- No faces: people seen from behind, from the side with the face out of frame, or hands and books only.
- No logos, signs, flags, readable text or brand marks anywhere in the frame.
- Men: white Saudi thobe with Hijazi tailoring (fitted cut, band collar, cuffed sleeves), no ghutra or a plain white one.
- Women: navy or burgundy abaya with a hijab of the same colour in Saudi style, **or** a black abaya with a black hijab and niqab in Saudi style.
- Licensed for commercial use (for example from Arabsstock, or generated by you).
